# Gym Crowd Prediction

## Project Overview
This project aims to predict gym crowdness using Machine Learning regression algorithms. Multiple models were trained and compared without hyperparameter tuning. After the initial comparison, KNN and Random Forest were selected for hyperparameter tuning. Random Forest achieved the best performance.

## Machine Learning Algorithms
- Linear Regression
- Ridge Regression
- Lasso Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Regressor
- Random Forest Regressor

## Model Optimization
- Initial model comparison without hyperparameter tuning
- Hyperparameter tuning for KNN and Random Forest
- Performance comparison of tuned models
- Random Forest achieved the best results

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Hyperparameter Tuning
8. Final Model Comparison

## Evaluation Metrics
- MAE (Mean Absolute Error)
- MSE (Mean Squared Error)
- RMSE (Root Mean Squared Error)
- R² Score
